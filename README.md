# Attendance Keeper PWA

A mobile-first attendance tracker with:
- Subjects
- Weekly timetable
- Present/Absent marking
- Attendance calculations and 75% guidance
- LocalStorage persistence
- Light/dark mode
- Installable PWA
- Offline caching

## Run
For full PWA/offline support, serve the folder over localhost. In VS Code:
1. Open this folder.
2. Use the Live Server extension, or run any local static server.
3. Open the shown localhost URL.
4. Use your browser's "Add to Home screen"/"Install app" option.

Opening `index.html` directly also works for the basic UI, but a local server is recommended for PWA service-worker support.
